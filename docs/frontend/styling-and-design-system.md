# Styling and Design System

## Principles

- Use a consistent design system.
- Prefer reusable design tokens.
- Keep spacing, typography, color, and radius scales consistent.
- Avoid arbitrary one-off styles.
- Ensure responsive behavior.

## Design Tokens

Centralize commonly reused values such as:

- Colors.
- Typography.
- Spacing.
- Border radius.
- Shadows.
- Breakpoints.
- Z-index layers.

## Components

- Use shared UI components where possible.
- Keep variants explicit.
- Avoid duplicating styles for equivalent components.
- Support accessible focus and disabled states.

## Responsive Design

- Design for small screens as well as desktop.
- Avoid fixed dimensions unless required.
- Test layouts at representative viewport sizes.

## Project-Specific Design

The actual color palette, typography, component library, and visual identity must be defined per project.
