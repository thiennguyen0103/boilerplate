# Project Documentation

This directory contains project-specific requirements, domain definitions, and architectural decisions.

These documents must be completed for each new project.

## Documents

| File                            | Purpose                                 |
| ------------------------------- | --------------------------------------- |
| `business-requirements.md`      | Business context, objectives, and scope |
| `domain-model.md`               | Domain entities and relationships       |
| `business-rules.md`             | Business rules and invariants           |
| `user-roles-and-permissions.md` | Roles and access policies               |
| `api-requirements.md`           | Project-specific API requirements       |
| `architecture-decisions/`       | Architecture Decision Records           |

## Important

Do not copy assumptions from another project without validating them.

Mark undecided requirements as `TBD`.

Record the owner and date when important decisions are finalized.
