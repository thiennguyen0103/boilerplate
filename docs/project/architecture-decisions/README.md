# Architecture Decision Records

Use this directory to record significant technical and architectural decisions.

Each decision should be documented in a separate file.

## Naming Convention

```text
ADR-001-short-decision-title.md
ADR-002-short-decision-title.md
```

## ADR Template

Create a new file using this structure:

```md
# ADR-XXX: Decision Title

## Status

Proposed | Accepted | Rejected | Superseded

## Date

YYYY-MM-DD

## Context

What problem or situation requires a decision?

## Decision

What has been decided?

## Alternatives Considered

What alternatives were evaluated?

## Consequences

What are the benefits, trade-offs, and risks?

## References

Related documents, discussions, or issues.
```
