# Unit Testing

## Scope

Unit tests verify small units of behavior independently.

## Backend

Prioritize:

- Domain behavior.
- Use cases.
- Validation.
- Error handling.
- Pure utility functions.

Mock external dependencies through interfaces.

## Frontend

Prioritize:

- Component rendering.
- User interactions.
- Hook behavior.
- Utility functions.
- Form validation.

## Guidelines

- Keep tests independent.
- Use descriptive test names.
- Test observable behavior.
- Avoid testing implementation details.
- Include success and failure scenarios.
