# Adding a New Feature

## 1. Understand the Requirement

Before implementation:

- Understand the feature's purpose.
- Identify affected applications.
- Identify relevant backend modules.
- Identify required API contracts.
- Identify data and authorization requirements.
- Identify acceptance criteria.

## 2. Backend

1. Define domain concepts and rules.
2. Define application use cases.
3. Define repository and service ports.
4. Implement infrastructure adapters.
5. Add presentation controllers and DTOs.
6. Add validation and authorization.
7. Add tests.
8. Update API documentation.

## 3. Customer Frontend

1. Create or update the feature structure.
2. Define API functions and types.
3. Implement pages and components.
4. Implement loading, empty, and error states.
5. Add form validation where needed.
6. Add tests.

## 4. Admin Frontend

If applicable:

1. Add feature routes.
2. Implement admin pages and components.
3. Integrate API operations.
4. Implement permission-aware UI.
5. Add tests.

## 5. Final Review

- [ ] Acceptance criteria satisfied.
- [ ] Backend authorization implemented.
- [ ] Input validation implemented.
- [ ] Tests added.
- [ ] Lint and type checks pass.
- [ ] API contracts are consistent.
- [ ] Documentation updated.
- [ ] No secrets committed.
